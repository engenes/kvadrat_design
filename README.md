# Квадрат — дизайн-система в Sites

Отдельный каталог для развития дизайн-системы приложения. Исходный импорт: `C:/work/kvadrat-laravel/docs/design`, 14 сентября 2026.

## Состав

- `dist/references/`: все 167 исходных файлов, без изменений.
- `dist/catalog.json`: реестр оригиналов с размерами и SHA-256, CSS-токены.
- `dist/index.html`, `styles.css`, `app.js`: оболочка каталога.
- `dist/library.js`: просмотр токенов, 28 скриншотов и HTML-эталона меню, чтение и поиск файлов.
- `dist/components.js`: 13 живых образцов компонентов с переключением вариантов.

Рабочее приложение Laravel/Nuxt не меняется. Этот Site не подключён к его API. Макеты `.dc.html` сохранены как исходники конструктора и сопровождаются скриншотами; их логика не исполняется. HTML-эталон меню открывается в изолированном просмотрщике. Живые образцы построены заново на исходных токенах; они не являются копиями компонентов Nuxt.

Скриншоты расписания исторические: актуальная ориентация календаря и порядок шагов описаны в импортированном `kvadrat-ds/MAP.md`. Полнота импорта проверяется по хешам, а не по числу файлов. Импортированные документы сохраняют исторический контекст; текущее поведение приложения определяется его OpenSpec.

## Продолжение работы

Редактировать живые образцы в `dist/components.js`, визуальные итерации — в `dist/styles.css`; оригиналы в `dist/references/` сохранять неизменными. При изменении референсов запустить `node scripts/import-references.mjs C:/work/kvadrat-laravel/docs/design`; команда обновит копии и реестр. На перенос текущих файлов повторный импорт не требуется.

Локальный просмотр: `node scripts/serve.mjs`, адрес `http://127.0.0.1:4317`. Зависимости и сборка не требуются. Проверка импорта и ссылок: `node scripts/verify.mjs`. После правок использовать существующий `project_id` из `.openai/hosting.json`.
