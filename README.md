## Навигация по страницам

Стартовая страница `index.html` (и маршрут `#pages`) показывает все готовые экраны: главную, каталог, объект, импорт-фиды, конструктор, галерею компонентов и обзор UX. Архив макетов и исходники вынесены в отдельную группу.

Меню «Недвижимость» и «Все объекты» открывают `property-catalog.html`. Поиск на главной передаёт выбранные параметры в каталог через GET. Карточки главной, каталога, похожих объектов и галереи ведут обычными ссылками на единственный свёрстанный фрейм `property-object.html`; отдельные страницы для каждой демонстрационной записи не создаются. Ссылка «Все страницы» возвращает в навигацию проекта.

Проверка всей перелинковки: `node scripts/verify-navigation.mjs`. После правок общих компонентов пересобрать главную, галерею, каталог и объект их четырьмя `build-*.mjs` скриптами.

- `dist/catalog.json`: реестр оригиналов с размерами и SHA-256, CSS-токены.

- `dist/library.js`: просмотр токенов, 28 скриншотов и HTML-эталона меню, чтение и поиск файлов.
- `dist/components.js`: 13 живых образцов компонентов с переключением вариантов.

Рабочее приложение Laravel/Nuxt не меняется. Этот Site не подключён к его API. Оригинальные макеты `.dc.html` сохранены без изменений; их собственный шаблонизатор не исполняется. Для `PageBuilder.dc.html` создан отдельный работающий редактор на исходных токенах и правилах сетки. HTML-эталон меню открывается в изолированном просмотрщике. Живые образцы не являются копиями компонентов Nuxt.

## Конструктор страниц

Исходник: `kvadrat-ds/source/page-builder/PageBuilder.dc.html`, справочник: `source/block-catalog/BlockCatalog.dc.html`. Сохранены 12 типов блоков и все минимальные/исходные ширины. Начальная страница «О компании» повторяет структуру исходника: слайдер, заголовок, преимущества, текст + форма, объекты, галерея, CTA.

- Поиск и добавление блоков, перенос мышью/касанием, изменение ширины ручкой, стрелками и ползунком. Вставка в свободные колонки либо новой строкой. Порядок и перенос между строками доступны также кнопками и списком в инспекторе.
- Редактирование текстов, настроек медиа и карточек, отступов, фона. Для объектов используются четыре демонстрационные записи; фильтр, ручной список номеров и сортировка работают на них. Внешнего источника данных нет. «Источник преимуществ» исходного макета заменён редактируемым содержимым.
- Отмена/повтор последних 80 правок (в пределах открытого редактора). Ввод в одном поле группируется. Автосохранение и ручное сохранение в `localStorage`, ключ `kvadrat.page-builder.v1`. Ошибки хранения показываются пользователю. Между устройствами черновик переносится JSON-файлом; совместного редактирования нет.
- Предпросмотр 1280 / 834 / 390 CSS-пикселей в отдельном iframe. CSS container queries перестраивают страницу. Масштабирование холста служит только выбранному устройству, панели адаптируются через CSS. В предпросмотре работают слайдеры, карусель, лайтбокс, аккордеон, переход к форме и проверка формы. Заявки не отправляются.
- Импорт/экспорт JSON со строгой валидацией структуры, ширин, настроек и ограничением размера. Экспорт HTML встраивает изображения, шрифты и стили — файл можно открыть без сервера. HTML содержит демонстрационные взаимодействия, подключение к API отсутствует. Исходная кнопка «Опубликовать» заменена честным экспортом макета.

Модель страницы и история: `builder-model.js`; реестр настроек: `builder-schema.js`; разметка блоков: `builder-render.js`; взаимодействия предпросмотра: `builder-preview.js`; редактор: `builder.js`. Один рендерер используется в холсте, предпросмотре и выгрузке. Проверка модели: `node scripts/verify-builder.mjs` (встроенные Node assertions, без зависимостей).

Проверено в браузере: редактирование/ширина, добавление в строку, перенос мышью и отмена, восстановление после перезагрузки, импорт JSON, выгрузка самостоятельного HTML, слайдер, галерея, форма, адаптивные панели. Оригиналы сверяются по SHA-256.

Скриншоты расписания исторические: актуальная ориентация календаря и порядок шагов описаны в импортированном `kvadrat-ds/MAP.md`. Полнота импорта проверяется по хешам, а не по числу файлов. Импортированные документы сохраняют исторический контекст; текущее поведение приложения определяется его OpenSpec.

## Продолжение работы

### Фирменный Select

Маршрут `#components/Select`: единая белая поверхность с радиусом 30 px, высота закрытого поля 60 px. Меню продолжает шапку вниз без зазора и скруглений на стыке; выбранное значение отмечено галочкой. В панели образцов используется тот же компонент высотой 44 px и радиусом 22 px.

Реализация — `dist/select.js` и `dist/select.css`. Исходный `select` хранит значение и остаётся доступным без улучшения JavaScript. Компонент поддерживает стрелки, Home/End, PageUp/PageDown, Enter/Space, Escape, Tab, поиск по первым буквам и reduced motion. Образец показывает обычное, заполненное, ошибочное и недоступное состояния, а также длинный список городов. Обработчики удаляются при смене образца или маршрута.

Эта итерация подключена к галерее компонентов и её переключателям. Публичные страницы и конструктор сохраняют текущие поля. Исторические исходники `dist/references/` не изменены.

### Страница объекта из локального JSON Figma

Страница `property-object.html` переносит фрейм Object: фотографии, карточку объекта и агента, описание, характеристики, карту и похожие объекты. Она переиспользует компоненты главной и каталога. Источник, повторный импорт, устройство и ограничения описаны в [OBJECT.md](OBJECT.md). Сборка — `node scripts/build-object.mjs`, проверка — `node scripts/verify-object.mjs`.

### Каталог из локального JSON Figma

Страница `property-catalog.html` собрана из экспорта Local Figma Reader: 503 слоя и 20 карточек фрейма Catalog. Она переиспользует карточки, поля поиска, шапку и подвал главной. Фильтры, сортировка, пагинация и просмотр объектов работают на сохранённых данных. Источник, проверки и ограничения описаны в [CATALOG.md](CATALOG.md). Сборка — `node scripts/build-catalog.mjs`, проверка — `node scripts/verify-catalog.mjs`.

### Главная из Figma
