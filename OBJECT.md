# Страница объекта из локального экспорта Figma

Источник: `АН КВАДРАТ (Copy)` → `Page 1` → `Object` (`88:0`), 1920 × 3343. JSON Local Figma Reader от 22 сентября 2026 содержит 292 слоя, четыре исходных изображения и превью. SHA-256 выгрузки и файлов записаны в `dist/object-page/provenance.json`. Рабочая страница — `property-object.html`, ссылка также есть в библиотеке Sites.

## Устройство

`dist/object-page/data.js` хранит извлечённые тексты, характеристики, контакты и четыре похожих объекта. `components.js` собирает страницу через общие шапку, подвал и карточки из `homepage/`. `media.js` задаёт разметку карты, `dialogs.js` — содержимое диалогов, `interactions.js` — галерею, диалоги, демонстрационную форму, расчёт платежа и навигацию похожих объектов. `styles.css` дополняет общие стили главной и каталога.

HTML собирается заранее и читается без JavaScript. Адаптив основан на CSS Grid/Flex и media queries. Работают выбор миниатюры, стрелки и увеличение фотографии, просмотр карты, открытие похожего объекта, обратный звонок и калькулятор. JavaScript не меняет мобильный шаблон; измерения карусели определяют только доступные позиции прокрутки. Страница макета помечена `noindex,nofollow`.

Три изображения переиспользуют побайтово совпавшие файлы `references/`: оба интерьера и фотографию агента. Добавлены оригинал карты и превью. CSS воспроизводит кадрирование `imageTransform`, скрывая интерфейс браузера, попавший в исходную фотографию карты. Оригинальные `phone-call.svg`, `full_screen.svg` и `li.svg` найдены в CSS [сайта агентства](https://novostrojki-orenburga.ru/) и сохранены без правок; отдельный реестр находится в `dist/object-page/assets/provenance.json`.

## Пересборка и проверка

Из корня этого отдельного сайта, без установки пакетов:

```text
node scripts/import-object.mjs "полный путь к .figma-reader.json"
node scripts/build-object.mjs
node scripts/verify-object.mjs
node scripts/serve.mjs
```

Повторный импорт нужен только при обновлении JSON. Импортёр привязан к узлам этого фрейма и останавливается при отсутствии ожидаемых текстов или фотографий. Реестр дополнительно загруженных SVG сохраняется при повторном импорте. После изменения компонентов достаточно сборки и проверки. Локальный адрес: `http://127.0.0.1:4317/property-object.html`.

`verify-object.mjs` сверяет SHA-256 и размеры исходных файлов, локальные ссылки HTML и CSS, разрешение импортов JavaScript, синтаксис связанного кода и соответствие опубликованной разметки результату `objectPage()`. Можно передать путь к JSON аргументом проверки для дополнительной сверки SHA-256 самой выгрузки. Эта статическая проверка не заменяет просмотр адаптива и взаимодействий в браузере.

## Ограничения источника

- Четыре миниатюры используют одну фотографию, как в Figma. Других ракурсов квартиры в выгрузке нет.
- В описании указаны 40 м², в характеристиках — 36 м²; сводка содержит «Кирпич», подробности дома — «Панельный». Эти расхождения сохранены. Третье преимущество безопасной сделки также содержит исходный текст-заготовку.
- Карта — оригинальное растровое изображение с собственным маркером. Фирменный векторный маркер из Figma не экспортирован и точный оригинал не найден, поэтому отдельный приблизительный маркер поверх карты не добавлен. Живой карты и координат объекта нет.
- Мобильный фрейм не приложен: адаптив является продолжением структуры десктопного макета.
- Цены, контакты, дата и ипотечный тизер воспроизводят старый дизайн. Калькулятор даёт демонстрационный расчёт по введённым параметрам, а не банковское предложение. Формы ничего не отправляют и не сохраняют; CRM/API не подключены. Laravel/Nuxt не изменялись.

## Проверено в браузере

Ширины 320, 390, 768, 1024 и 1920 px: без горизонтального переполнения страницы; похожие объекты прокручиваются внутри своей области. Галерея проверена кнопками и клавиатурой, включая Escape и возврат фокуса; карточки ведут обычными ссылками на единственный свёрстанный макет объекта. Проверены форма консультации, нулевая ставка и недопустимый взнос в калькуляторе, раскрытие сохранённой карты. Ошибок JavaScript и незагрузившихся изображений не обнаружено. При ширине 1920 px высота страницы — 3343 px; ключевые вертикальные позиции совпадают с источником с точностью до 1 px. Полное попиксельное совпадение не заявляется.
